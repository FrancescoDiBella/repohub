# Checklist

An example RepoHub plugin: a release checklist on each repository's page (the **Checklist**
section) and a **Checklists** page with the progress of every repository.

Start your own plugin from it: **Settings → Plugins → Create a plugin** writes a copy into your
plugins folder, and RepoHub reloads it each time you save a file. The guide is
[`docs/PLUGINS.md`](https://github.com/FrancescoDiBella/repohub/blob/main/docs/PLUGINS.md).
